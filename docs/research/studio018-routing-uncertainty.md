# Studio018 routing uncertainty at position zero

For the closed Studio017 input, the reference top eight are defined by its own corrected scores in each of 42 routed layers. Its eighth and ninth scores were distinct even in layers 23, 33 and 34. Those three cutoffs failed the stricter test that asks whether the same eight IDs would win throughout a prescribed interval around **every** score. There is no native score observation for this input.

## What survives serialization

For each routed layer the reference sealed 288 FP32 corrected scores, eight expert IDs, eight FP32 normalized weights represented as JSON numbers, the cutoff gap, and routed/shared hidden outputs. The internal `router_logits` argument to the event sink is discarded. The manifest includes no uncorrected sigmoid vector, correction-bias vector, 4096-component post-normalization router input or native counterpart. A checksum identifies a checkpoint but supplies no tensor coordinates. [Emitted event](../../scripts/research/studio017_ref_graph.py#L254), [persisted route fields](../../scripts/research/studio017_ref_output.py#L62).

If $q_i$ is a stored selected weight, the ideal relation is $q_i/q_j=p_i/p_j$ for positive scores. A reported ratio is approximate because each division and scaling was rounded. More precisely, with the reference denominator $D=\mathrm{RN}_{32}(\sum_{j\in S}p_j)$, the stored value is $\mathrm{RN}_{32}(2.5\,\mathrm{RN}_{32}(p_i/D))$. Neither $D$ nor any unselected weight is stored. Define $I(c)$ as the interval between the two binary32 rounding midpoints around $c$, with endpoints assigned by ties-to-even. Since $p_i\in[0,1]$, the bias must lie in $[\inf I(c_i)-1,\sup I(c_i)]$ and be representable in FP32. If the bias were independently known, $p_i\in (I(c_i)-b_i)\cap[0,1]$. These are constraints, not reconstructed scores.

An exact synthetic ambiguity uses the same corrected centers and route report twice. Choose eight centers $1+j/64$ for $j=0,\ldots,7$ and zero for every unselected center. Set every $p_i=1/2$ and $b_i=c_i-1/2$. Alternatively use every $p_i=1/4$ and $b_i=c_i-1/4$. Both choices have exactly representable FP32 biases, the same eight selected IDs, identical corrected vectors and weights 0.3125 for all eight. The FP32 logits 0 and the FP32 representation of $-\log 3$ respectively give these sigmoid scores after reference rounding. Even knowing the scores would not in general reconstruct $W$ and $x$ from their dot products. This example establishes ambiguity of the **saved router observables**. It does not posit two different histories for the identified real checkpoint.

## Meaning of the frozen bound

Studio017 uses $e(c)=0.00004+0.000004|c|$ on represented corrected scores. For selected set $S$ and complement $U$, it requires $G=\min_{i\in S}(c_i-e(c_i))-\max_{j\in U}(c_j+e(c_j))>0$. If each candidate score lies inside its respective interval, a positive $G$ proves every selected score remains strictly above every unselected one. $G=0$ permits equality in the interval model. $G<0$ permits overlapping intervals. Neither implies that a real implementation moved a score or changed IDs. The implementation widens FP32 centers to binary64 before computing endpoints. An exact rational replay may differ in the last binary64 bits. [Frozen criteria](../../scripts/research/studio017_ref_criteria.py#L57), [eligibility conjunction](../../scripts/research/studio017_ref_grade.py#L229).

The constants originated in bounded selector fixtures with at most eight positive terms and separated cases having a positive denominator above 0.1. The earlier contract applied the tolerance to **returned weights**. Its source-composed cases used hidden width at most 16. They separately budgeted projection error as $\gamma_H\sum|x_jW_{ij}|$, one quarter of that error plus an engineering $16u$ sigmoid allowance, and bias-add rounding for ranking. The $16u$ allowance was never a proved transcendental guarantee. Copying the numerical tolerance to 288 corrected scores at width 4096 created a prospective acceptance target. Those small fixtures supplied no global error bound for the full cold forward. [Original fixture criteria](../glm53-flash/source-environment-v1/criteria.md#L16), [source-composed caller contract](../glm53-flash/router-caller-v1/contract.md#L13).

For the same represented $b_i$ at both endpoints, write $c= p+b_i+r$, where $r$ is that addition's rounding error. Then $c_N-c_R=(p_N-p_R)+(r_N-r_R)$. The fixed bias cancels **within** one expert's cross-runtime difference. The difference $b_i-b_j$ between experts affects membership. For a finite interior FP32 result, the magnitude of each rounding error is at most half the larger of the adjacent spacings. With $p_R=0.5$ and $p_N=0.5+2^{-24}$, bias +16 rounds both sums to 16.5 and bias −16 rounds both to −15.5. Bias −0.5 instead gives 0 and $2^{-24}$. The large correction makes the *frozen relative term* larger as a function of $|c|$. That term does not measure bias uncertainty. Replacing $|c|$ by $|p|$ would change the criterion.

For a common gate row $W_i$, the input contribution before projection rounding is $W_i(x_N-x_R)$, bounded by $\sum_j |W_{ij}|\,|x_{N,j}-x_{R,j}|$. A complete prospective bound must add each projection's numerical error, propagate through sigmoid (the ideal derivative is at most $1/4$), add sigmoid implementation errors and the two addition roundings above. Any claimed $\gamma_H$ bound requires a justified accumulator model, represented operands and magnitude bounds. Applying the ideal sigmoid derivative alone cannot bound two implementations at different inputs.

For a hand-checkable upstream discriminator use $W=(1,-1)$, $x_R=(1,1)$, $x_N=(1+2^{-7},1)$. This changes one represented BF16 coordinate by one adjacent value. The exact logits move from 0 to $2^{-7}$. The reference-form FP32 sigmoid moves from 0.5 to 0.501953125, more than 40 times $e(0.5)=0.000042$. A competing zero row with FP32 bias 0.00009 has corrected center 0.5000900030136108. Its reference conservative lead is approximately 0.00000600265, yet the changed activation reverses this pair. Seven permanently higher experts and 279 lower experts embed this boundary pair in a top-eight-of-288 selection. Padding the two coordinates with zeros supplies width 4096. This synthetic construction demonstrates failure of the *inference from a BF16 neighbor to the FP32 score bound*. It makes no prediction about the actual three layers.

## Prior review and remaining evidence

The Studio017 source reviewer accepted this experiment with an explicit false-refusal exception E5. It identified lack of composition across BF16 stages and the tighter FP32 targets. The comparison addresses the specified mathematical model and rounding boundaries. Shared methodological assumptions, 11 position-zero MLA query paths without an independent numerical witness and the structural state-offset count limit broader claims. The result reviewer manually inspected the three failing score populations and relied on the sealed grader for the 39 passes. It did not recompute file digests or observe a native route. The original source and result sessions were `44c5e903-086c-4124-904d-85711d8b8a3d` and `42d1cc7b-8f96-4f1d-a3fe-db7d4ecd7635`.

The three refusals are valid under the frozen sufficient test. Identical-input projection uncertainty, full-forward input uncertainty, and the as-yet-unobserved native differences remain distinct quantities. A prospective empirical comparison could measure actual membership and discrepancies on this one input under a separately approved diagnostic scope. A certified replacement bound would need independently justified per-row and upstream enclosures for every route. Neither inference can be made by reclassifying the existing reference as eligible.
