# Studio017: one cold text token

This opt-in research target is limited to GLM-5.3-Flash mixed 4/8-bit at publisher revision `d43ea8b407ce4e9c25e6ac9baec3feab70d9f5f3`. It does not change the product engine. Start from the literal tokenizer-defined pad/EOS ID 154820 as a single input at position zero. This is not a BOS or templated chat message. All 18 original shard bodies must be authenticated. The oversized tokenizer body is not needed to supply a numeric ID: the two publisher-bound configuration files identify the named token. Preserve the vision tensors without evaluating them.

The Rust caller expands a single embedding into four mHC streams. Each of the 45 layers applies two mHC transforms. There are 34 KDA and 11 NoPE MLA attention blocks, three dense and 42 routed-plus-shared FFNs; the FP32 router selects eight of 288 experts from its own corrected sigmoid scores and weights them with normalized *uncorrected* scores times 2.5. The candidate uses copied native affine projection tiles on the explicit GPU stream and represents the small vector operations in Rust at their model dtype boundaries. The sorted reference membership is independent of the native partition order. Preserve raw route order/weight pairing, check numerical reduction separately, and refuse an ambiguous cutoff. The only returned generation is the greedy ID after final stream mean, RMSNorm and the entire untied 154,880-logit head.

The independent CPU reference decodes the original affine weights using shifts and masks and accumulates small tiles in binary64, with explicitly represented BF16 and FP32 model boundaries. It imports neither the candidate nor MLX. A quality threshold is not a global error theorem: require agreement for every final logit and the preregistered stream/state/route comparisons. A narrow reference margin or an unstable route prevents qualification. A sampled successful subset, uniform next-token agreement, or a plausible word cannot close this result.

**Resource derivation.** Original text data traffic for a one-pass plan is at most 13,650,291,192 logical bytes (4,352 for the embedding, 4,756,340,736 selected expert bytes, 8,893,946,104 trunk bytes). Some inactive long-context indexer parameters need no payload reads. Tiling is along output rows with a whole input dimension per dot product: at most 64 native rows × 16,384 input lanes, or 16 reference rows × 16,384 lanes. The largest native packed-plus-metadata tile is 1,114,112 bytes (8-bit/group 64); imports copy data. The reference F64 decoded tile is at most 2,097,152 bytes before separate temporary words/codes and outputs. The unquantized 288×4,096 router expands to 4,718,592 native F32 bytes or 9,437,184 reference F64 bytes. No full-model dense expansion. One KDA recurrent state is 4,194,304 bytes; the other cache is three BF16-represented 24,576-channel rows. Each layer's evidence is streamed to private files, never carried as weights into the next. Cap each original role output at 256 MiB. The full checkpoint is storage, not a residency request.

Keep a separate combined reservation for the heavy process and monitor: 2 GiB per role, including 384 MiB for parent and transient child admission and 1,664 MiB for the numerical job. The native GPU allocator is limited to 512 MiB, including imported tiles/operation temporaries; its reusable allocation cache is disabled for this process. Budget up to another 512 MiB for host vectors, receipt copies, source metadata and transient tile readback, and 640 MiB for loaded runtime/OS slack. For the CPU job reserve 384 MiB for transient arrays and file handling, the remainder for single-thread NumPy/OpenBLAS, the interpreter, and slack. These are conservative reservations to be checked against *current* safe headroom, group RSS, pressure and swap; no run is admitted on their own. Require at least 16 GiB above the combined reservation. No warm repeat, populated-state decode, benchmark, physical I/O, vision or quality result is implied.

Model equations and specific upstream sources are pinned in [the selector/source contract](../glm53-flash/source-environment-v1/source-contract.md), the [decoder topology](../glm53-flash/decoder-topology.md), retained upstream hyper-connection, gated-delta, router and language source snapshots, and the checkpoint's own recipes. Compilation, synthetic controls and historical numerical results do not establish a real full-model result. Reference and native phases require different private immutable grants, original claims, independent grading and separate artifact custody.


**Four-bit affine correction.** In the pinned Metal implementation, the bias contribution of a packed 4-bit dot can use BF16 sums of four activations before entering the FP32 accumulator. For code 8, scale 1/16 and bias −1/2 every weight is zero, yet the typed partial sums predict 3/512 for the prefix [1, 1/256, 1/256, 1/256]. In the original five-layer control, independent reconstruction of that rule reproduced a two-step BF16 error at final logit 1. The bounded replacement is a plain packed Metal dot: BF16 activation, scale and bias; the original low-first U32-packed 4-bit weights; an FP32 MAC accumulator; and a single explicit BF16 output conversion. It reads the original tile directly. The reference, numerical thresholds, input and installed libraries remain unchanged. The corrected five-layer case and zero-row control passed on hardware with reads of real model data denied. This evidence covers only those synthetic cases. The 8-bit projections use the existing native affine primitive.
