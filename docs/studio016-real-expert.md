# Studio016 scoped real expert qualification

Default-off `real-flash-expert` builds one diagnostic child. No serving model,
routing, weight conversion, prompt generation, storage-bypass or benchmark
contract changes. Layer 3 is the first routed layer in the fixed configuration;
expert 0 is selected statically. Nothing implies the router selected this expert.

The binding lists the nine ranges and original metadata digest. The direct
reference binder checks original file descriptors and their namespace witnesses;
only the selected shard is streamed in full, once for publisher SHA-256. Other
shards are identified at metadata scope. No whole-model revision attestation.
One frozen 4096-element F32 input uses deterministic dense signs of 1/4. This
is an expert-boundary test vector, not a real prompt state. No vector search.

The Rust child resolves original packed U32 and BF16 affine metadata with the
accepted BoundedSource and verifies every range and digest. Each role uses one
synchronous BufferedRequested fill, then retires its reader. The sealed tuple
moves into the resident host arrays only after all fills succeed. It is copied
through the inherited guarded QMM bridge. No asynchronous coordinator, replay,
warm repeat, NoCache arm, or dense decoded native weights. Requested aligned
windows can include small edge padding; physical traffic is unknown.

The native graph is gate, up, upper-only min(gate,10), SiLU, symmetric
clip(up,-10,10), multiply, then down. The row-streamed Python reference
interprets original little-endian nibbles and affine metadata independently.
Each projection uses exact dyadic contraction and per-row gamma with N=273
or 145 (inherited M=1 4-bit group-64 family). The independent activation
encloses exp on the fixed rational lattice, using the inherited local 1/128
absolute bound and 20*Bg+10*Bu propagation. The end-to-end down bound is
formed from original-weight ideal intervals plus propagated hidden uncertainty
and a prospective projection-rounding bound; candidate values never set it.
A separate local down check uses the actual F32 hidden, with all existing QMM
domain checks, including the nonzero 2^-32 floor. This does not prove the
older FR09 predicate about every point in a coarse interval. The prior
refusal remains a refusal with zero native calls. Both error checks and exact
clamp readbacks must pass on all coordinates. Original-only reference runs
first, candidate second, grade third.

The stage, activation, resource sampling and reference math adapt individual
files selected_execute.rs, selected_adapter.rs, selected_resources.rs,
activation_selected.cpp, f020_selected_r1_v2.py and f020_selected_compare_v2.py
from adda03ad9097372fe7e9d8fa59d2853281af6c1f. No old grant, snapshot,
input, result, dirty source or reference output is imported. Tests exercise
the actual rational codec and changed-nibble/bias controls. Host reference,
native binary, review and result bind the same frozen bytes and criteria.

The initial campaign launcher independently rechecks the private immutable
grant and checksum, source, predecessors and binary. The shared installation
uses one permanent initial claim. Each child must belong to its supervisor,
must create its start receipt exclusively, and cannot reuse a prior output.
There is no corrective entrypoint in this version. The supervisor must
verify authenticated review, coverage, evidence, CI and request contents
before publishing the grant. A claim without completion is not retryable.
The finite allowance here is one reference, one candidate and one grade.
Each lasts at most 1800 s, campaign 7200 s, monitored combined 2 GiB (1 GiB
job, 256 MiB supervisor, 256 MiB helpers, 64 MiB allocator and 448 MiB
reserve); no process-wide allocation cap is claimed from RSS sampling alone.
The original reference and candidate output descriptors are sealed before the next
stage; their identities stay in the parent until final grading. The native child
confirms all three loaded dylibs and its admitted shard descriptor stamp.
At launch require 16 GiB estimated reclaimable headroom (the smaller of the
kernel availability estimate less one point and free pages plus half the pageable
external pages), and normal
pressure. Stop on abnormal pressure, or swap growth over 256 MiB on three
consecutive samples. Artifact budget 10 GiB; private evidence 512 MiB.
The selected staging uses 14,155,776 destination bytes, one reusable-role
scratch below 4.5 MiB, bounded 2,073,600-byte staged receipts and at most
33,734,653 bytes policy transport. No whole-model memory estimates.

A full native Flash token still requires a model forward owner for embedding
and residuals, hybrid attention/recurrent state, dense FFNs, router/top-8
selection and weighted/shared-expert reduction, final norm/logits and
token selection. This unit does not qualify any of those paths or vision.
