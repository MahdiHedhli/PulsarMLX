# Owned data and state

Original: immutable packed nine buffers, strict external source descriptor,
fixed original x bytes, verified component and framing hashes; no path reload.
Certificate: immutable exact tuples, E denominator Q (D uses Q*2^39, R gamma145 denominator, Y2^-256), checker/proof/profile and original
digest; E identity covers all2048 lanes. Candidate data absent from constructor.
Buffer: immutable bytes, dtypeF32LE, fixed shape, digest; no mutable alias.
Identity: source/build/profile/contract/attempt/reference hashes, execution scope
CPU_PUBLIC_SYNTHETIC. Mock receipts confer no native authority.
Owner: serial claimed identity, state, immutable retained G/U/H/Y, transcript,
resources and dispatch counts. Failure from any claimed state->TERMINAL refusal;
cleanup exactly once. No reset/replay/deserialization into a runnable owner.
Receipt: immutable canonical serialized bytes, previous digest, state, checked
buffer hashes and identity. Final receipt states mock-only and unqualified.
