## Practical limits and next gates

The session rejects unmarked/oversized bindings before reading payload and never calls the production admission entry point. It authenticates fixed text and exact expert/PLE spans only inside a generated <=16 MiB fixture. The fixture helper deliberately binds a parsed two-layer catalog using the private test token; it is not a new production admission API or a numerical Qwen fixture.

Observation values are independent **injected test data**, never derived from scheduler/ledger counters. They are not actual macOS process footprint, available headroom, swap or MLX measurements. The control-metadata reservation is a bounded allowance, not an exact accounting of Python/container/trace copies; interpreter allocations, allocator retention and OS page cache require real independent observation and calibration before execution. The verified-reader scratch allowance reserves two captured chunk sizes; it does not implement a zero-copy I/O engine. Reclamation after `BufferError` is logical owning-payload evidence, not proof that the OS/MLX immediately returns physical pages.

Completion objects and duplicate device owners are CPU bytearrays in a synthetic protocol. No real asynchronous I/O, device submission, GPU fence, MLX eviction, Qwen graph or model output is qualified. The reviewed descriptor primitive attempts all closes and surfaces errors; an actual OS close error can leave that descriptor's fate uncertain, as previously documented. The close-error fixture deliberately closes then raises, and proves the remaining descriptors are attempted; it does not eliminate that OS-dependent risk. Incomplete traces/owners cannot support a successful terminal claim.

Steps 4–7 remain separate: authorized independent source review, actual sampler/backend and hashed environment, independently pinned numerical fixtures/parity, a later separately authorized bound real-file session, then paged correctness and performance. External transmission and publication are not authorized in this slice. The 48/40/16 GiB planning gates remain intact. No stock full-model loader is made safe by these tests.

Constitution check: source and generated fixtures are additive, original Qwen/shared/GLM source remains untouched, no third-party code/weights/secrets are copied, synthetic acceptance is separated from production claims, and exact local evidence plus diff/secret/large-file checks accompany the slice. No Rust/backend change or new Linux/CUDA qualification is claimed.
