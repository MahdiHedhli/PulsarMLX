## Findings and local disposition

1. **Pager stop under competing actual demands (reviewer: high).** The reviewer correctly observed that `BoundedPager.next_io()` stops when a queued demand cannot fit alongside non-evictable actual demand pages and no speculative hint can be invalidated. This is an explicit fail-closed behavior in the already-reviewed synthetic pager: `test_fixed_text_weights_reduce_page_budget` asserts the stop when fixed text and a live demand consume the page allowance. The follow-up reviewer agreed it is a separate production scheduler behavior question, not a change required in this approved adapter-fixture slice. The suggested unconditional `return None` would change the protected scheduler contract and might wait indefinitely if a live demand is never finished. **Disposition:** preserve the reviewed scheduler here; require an explicit bounded wait/backpressure policy and deadlock/latency tests before production serving. The adapter's synthetic tests do not establish serving availability under multiple concurrent routes.
2. **`MemoryLedger.retire_all()` ignored an exported-view retention (reviewer: low).** Confirmed. `retire()` returns `False` when a child view prevents bytearray clearing, and `retire_all()` previously ignored that result. The new adapter module now records a `BufferError` for the retained owner while attempting every other owner. `test_retire_all_reports_exported_owner_and_retires_other_owners` verifies the error, retained accounting, retirement of the unencumbered owner, and later collection after the view releases. The follow-up reviewer confirmed the repair for this synthetic contract. Multiple cleanup errors remain attached with `add_note`; partial retirement is deliberate and the retained owner stays counted. **Disposition:** fixed in the additive adapter module, with no change to the original scheduler/catalog/verified-file modules.

The raw follow-up report contains imprecise `file:///scripts/...` links and places the scheduler test under the wrong test filename. The actual test is in `scripts/research/tests/test_qwen38_bounded_pager.py`; this local disposition uses the committed source as authority.
