## Session, staging and stop/drain contract

Preserve 48 GiB **aggregate Qwen process tree**, 40 GiB **all weight owners**,
8 GiB **all other owners within 48**, and 16 GiB **available system reserve**.
Sequential reference/candidate processes may not silently create an extra
48 GiB allowance. A larger Studio memory size cannot relax these gates.
Fixed text tensor bytes are historically 5,348,837,400, included inside 40 GiB;
vision/MTP are excluded. Quantized packed weights, affine scales/biases,
resident and pending pages, expanded/dequantized/device copies, backend cached
owners and still-retained exports all count until actual release. Duplicate
staging/KV/activations/runtime, Python heap and verifier scratch count inside
8 GiB. Assign each owning allocation once; never subtract an owner because its
logical page was evicted. Device weight copies remain weights even when pending.

Start with two 16 MiB staging slots (32 MiB total); authenticated hash reads use
1 MiB chunks. A page exceeding a slot requires a separately source-reviewed
segmented upload; do not widen staging or allocate the whole page behind the
ledger. Reserve all owners and prospective transfers before allocation; sample
before and after each allocation. Concurrent authenticated reads require
serialized verifier scratch or separately reserved scratch per operation.
The fixture session/store retain their existing authenticated marker and
16 MiB **fixture** cap; they are not a production loader.

After separate payload permission, the production session must call the public
`admit_checkpoint_bound` path to repeat full-file verification, parse through
retained descriptors and keep that **live** `BoundCheckpoint` bound to its exact
catalog/files for its entire lifetime. Read pageable data through
`BoundCheckpoint.read_page_into`; fixed tensor loading needs an equally
authenticated bounded descriptor/span path before this gate can pass. No
pathname reopening, saved admission receipt, caller-supplied catalog or fixture
private-constructor token may substitute. Changed content, identity, symlinks,
short/partial reads, poisoned/closed bindings and catalog drift stop the session.

Actual router IDs/weights and PLE rows alone authorize computation. Hinting may
stage bytes but not alter routes, arithmetic or tensor interpretation. Original
ticket/lease/borrow and completion identities bind request generation, owning
buffer and device stream. Cancellation stops admission; it cannot reuse old
owners or acknowledge completion. Poll the cooperative wait check at least
every 5 ms; retain its fixed 5 s queue deadline without renewal. A request has a
120 s wall deadline including I/O and device work, not whole-file admission.
Whole-file admission has a separate proposed 30-minute wall limit and at most
16 MiB scratch; an owner must separately authorize/calibrate that I/O gate.

Expiry, pressure, mismatch, allocation failure or sampler loss stop **new** work
immediately. Drain actual I/O and GPU operations before reclaiming their owners;
preserve original callbacks and surface primary plus cleanup errors. A 10 s
drain deadline is diagnostic, not permission to free live device memory. If a
fence never arrives, quarantine the session and escalate; never reuse those
buffers or report clean shutdown. Process termination/recovery needs a reviewed
backend strategy and actual owner authority, not a fabricated fence.

## Numerical probes and frozen reference tolerances

Comparison is elementwise `abs(actual-reference) <= atol + rtol*abs(reference)`.
Reject wrong shape/dtype/order, NaN/Inf and missing probes first. No aggregate
metric may hide an element failure. Tolerances below are candidate **acceptance
requirements**, not observed accuracy; cannot widen after seeing a failure.
They introduce no change to earlier tolerances. Compare arithmetic at matching
dtype/quantization, with exact frozen inputs and named intermediate arrays.

| Probe | Frozen inputs / mandatory independent output | Acceptance |
| --- | --- | --- |
| Scalar norm convention | `[3,4]`, raw `[.25,-.25]`, converted `[1.25,.75]`, epsilon `1e-6`; all eight centered suffixes in the harness | Decimal goldens: atol=rtol=`1e-12` locally; future FP32 primitive atol=`1e-6`, rtol=`1e-5` |
| Converted/raw layout | Converted stored multipliers unchanged; raw HF +1 exactly once for `hc_norm`, q/k norms, indexer q/k layernorms and PLE key/query/conv norms | Exact layout metadata and transformed tensor identity; raw-vs-converted FP32 outputs as above; no shift for `linear_attn.norm` or vision norms |
| DeltaNet q/k | `[3,4] -> [.6,.8]`, `[1,-2,2] -> [1/3,-2/3,2/3]`; zero/tiny vectors exercise the analytic clamp policy only | Nonzero FP32 L2 atol=`1e-6`, rtol=`1e-5`; squared norm check same bound. Freeze upstream epsilon value/placement and recurrent gate/state equations before zero/tiny or full DeltaNet parity |
| N-gram seed | Explicit integer seed1234; future independently frozen history/hash multipliers, overflow width, moduli and PLE shard/row outputs, plus seed0 negative control | Exact integer rows/IDs at all queried positions; a marker containing1234 is not a hash oracle. **Upstream row goldens absent** |
| EOS / request reset | Both248046/248044; repeated stops, each suffix vs fresh session, packed vs split controls | Exact history/row/stop/token IDs; recurrent/conv/KV/PLE states and logits compared to reference. | Sparse-prefill boundary | lengths2047/2048/2049/2080, query positions around2048, current partial block, future-only mutation, full-vs-chunked prefill, sparse selection forced under independent fixture | Exact visible mask and selected block/route IDs. | Quantized fixture | Independent known affine triples spanning shard/row tails,4/8-bit/group32/64; canonical dequantized outputs/orientation | Exact packed bytes/metadata; FP32 dequantized atol=`1e-6`, rtol=`1e-5`. Float route weights atol=`1e-5`, rtol=`1e-4`, selected expert IDs exact |

The BF16 and logits bounds are provisional reviewable requirements, not a
mathematical guarantee over arbitrary long inputs. Freeze specific independent
fixture outputs before the first candidate run. Tiny routing fixtures must
avoid ties (minimum selected/unselected score gap `1e-3`); integer route failure
still fails regardless of floating tolerance. Real checkpoint routes/logits
need a separately captured trusted paged compatibility arm and an approved
reference execution, not the synthetic fixture. No full360 GB BF16 reference
or full unbounded converted-model baseline belongs within these limits.

Future reference receipt must record immutable upstream revision/source hashes,
complete config and initialization algorithm, seed1234 (separate Python/NumPy/
Torch/MLX RNG algorithms and states, or identical explicit tensor inputs), lock,
interpreter, producer commit, dtype/quantization, exact input/tensor SHA-256 and
canonical little-endian array shape/bytes/hash. Backend candidate receipts must
bind the same fixture and input hashes, distinct producer implementation,
namespaced device/session/operation IDs, original completion evidence, sampler
trace, output tensors, tolerances and individual pass/fail. Independently capture
reference values before candidate invocation. A shared buggy generator or
matching port/candidate outputs does not supply independent HF correctness.
Upstream goldens and producer hashes are currently absent, so model parity is
explicitly **blocked** despite the 27 passing analytic probes.
