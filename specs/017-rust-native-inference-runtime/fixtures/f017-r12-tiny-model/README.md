# Feature 017 R12 tiny model fixture

This directory contains a deterministic, project-generated two-layer
`glm-dsa` fixture for checkpoint-free testing. The two `.fixture` files use
the GGUF v3 container format but contain only synthetic values generated by
`scripts/research/generate_f017_r12_tiny_model.py`; they contain no bytes from
the GLM-5.2 checkpoint or any other external model.

The fixture is covered by PulsarMLX's MIT license. `checkpoint.json` binds both
shards and the merged tensor catalog, while `model.json` binds the independent
Python/NumPy oracle, 105 tensor roles, two complete layers, expected routes,
full logits, top-k ordering, and the selected token.
